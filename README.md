# AI OS Community

Best Practices, Toolkits und Add-ons rund um ein produktives **AI Operating System** mit Claude Code, Obsidian, MCPs und Routines.

Dieses Repo ist die offene Community-Ressource zur AI-Mastermind-Workshop-Reihe von [Affom Birhane](https://github.com/affm777). Wer am Workshop teilgenommen hat oder eigenstaendig ein AI OS aufbaut, findet hier:

- **Schritt-fuer-Schritt-Anleitungen** zu konkreten Setups und Migrationen
- **Bug-Fixes** und Workarounds aus der Praxis
- **Best-Practice-Patterns** fuer Vault, Skills, MCPs und Automatisierung

## Struktur

```
toolkit/        in sich geschlossene Anleitungen (Migration, Setup, Bug-Fix)
```

Weitere Bereiche (best-practices/, examples/) wachsen mit der Zeit.

## Nutzung

```bash
git clone https://github.com/affm777/ai-os-community.git
cd ai-os-community
```

Den passenden Unterordner oeffnen, README darin Schritt fuer Schritt durchgehen. Jedes Toolkit ist eigenstaendig und greift nicht auf andere Teile zu.

## Beitragen

Pull Requests sind willkommen. Kriterien fuer neue Eintraege:

- loest ein konkretes Problem, das mehrere Nutzer haben
- funktioniert ohne den Rest des Setups (in sich geschlossen)
- mit einer Schritt-fuer-Schritt-Anleitung dokumentiert
- keine personenbezogenen Daten, API-Keys oder Secrets
